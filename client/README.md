# client

The React front end. Bootstrapped with
[Create React App](https://github.com/facebook/create-react-app).

**Don't run commands from this directory** — the front end and the dev API are
started together from the repository root:

```bash
cd ..
npm run dev
```

See the [root README](../README.md) for setup, and
[docs/CONTENT-GUIDE.md](../docs/CONTENT-GUIDE.md) for editing site content.
